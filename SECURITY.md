# Security policy

Security fixes are supported on a best-effort basis for the latest published
release. Pre-release development snapshots and older releases may receive fixes
at maintainer discretion.

Report a suspected vulnerability through GitHub private vulnerability reporting
for the authoritative repository. Do not disclose sensitive details,
credentials, patient data, or an exploitable vulnerability in a public issue.
No private reporting email address is currently designated.

Operators are responsible for secure deployment and configuration, credentials,
network controls, access control, PHI handling, local data protection, dependency
updates, and compliance in their own environment. The project provides no
security response SLA.
