# Security policy

Security fixes are supported on a best-effort basis for the latest published
release. The clean RRP 1.0 development line is currently unreleased and has no
operational or security support claim.

Report a suspected vulnerability through GitHub private vulnerability
reporting for the authoritative repository. Do not disclose sensitive details,
credentials, patient data, private hospital information, or an exploitable
vulnerability in a public issue. No private reporting email address is
currently designated.

Operators remain responsible for secure deployment and configuration,
credentials, network and access controls, protected-health-information
handling, local data protection, dependency updates, and compliance in their
own environments. The project provides no security response SLA.
