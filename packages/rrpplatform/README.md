# `rrpplatform`

`rrpplatform` is the main internal implementation package within RRP software.
It is versioned independently from the RRP product and currently establishes
only its package namespace and one-way dependency on `rrpruntime`.

The package is not an installation mechanism, operator interface, project API,
or generic analytical framework. Reusable orchestration and product support
remain repository-owned until their accepted extraction increments.
