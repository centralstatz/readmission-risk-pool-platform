# `rrpruntime`

`rrpruntime` is the dependency-light internal R package owner for future
implementation-neutral Readmission Risk Pool runtime responsibilities. Its
package version is `0.3.0.9000`, independently of the RRP product development
identity `1.0.0-dev`.

At Stage 2 Increment 2.A, the package is deliberately behavior-free. It uses
only base R package machinery, exports no callable API, and does not implement
canonical admission, eligibility, temporal state, risk requests, providers,
operational history, products, project behavior, or installed-resource access.

The package is internal software source. It is not the RRP product, an operator
interface, or evidence that RRP 1.0 is installed, released, or clinically
validated.
