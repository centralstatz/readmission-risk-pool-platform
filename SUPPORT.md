# Support

Community support is best effort through the authoritative repository's GitHub
issues and discussions. Questions and diagnostics must be reproducible and
privacy-safe; never include patient data, credentials, private mappings,
connection strings, raw records, or confidential business material.

The clean RRP 1.0 line currently contains no executable or installable product,
so it has no operational support or platform support matrix. The published
`v0.1.0` release remains a separate immutable historical release.

There is no support or response-time SLA. The software and documentation are
provided without warranty as stated in the Apache License 2.0. CentralStatz
professional services are separate and optional; use of RRP creates no
consulting, support, or service entitlement.
