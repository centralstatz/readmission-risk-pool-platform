# Fictional adopter producer example

This complete, deterministic, nonclinical example demonstrates the editable
Hospital Implementation trust/composition pattern with a denormalized case
export and independently loaded activity feed. It is adapted from the Phase 10
independent producer fixture and remains conformance/onboarding evidence only.

Its source objects, local identifiers, codes, and timestamps are not a required
hospital source shape. Generic Platform code does not know this example's
identity or fields. The synthetic reference remains the shipped Platform
reference; this example runs in separate state.
