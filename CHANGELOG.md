## [0.1.0] — 2026-09-06

The first public release provides:

- versioned canonical bundle, clinical profile, producer, runtime, provider,
  persistence, logical-product, deployment-artifact, and diagnostic contracts;
- synthetic reference production and a fictional independent adopter producer;
- provider-neutral estimation, append-oriented DuckDB history, YAML products,
  and a product-only Shiny reference application;
- stable human initialize, doctor, run, inspect, materialize, validate, and
  deployment-realization operations;
- a generated Hospital Implementation with an exact embedded Platform archive,
  one top-level `renv` environment, trusted producer composition, standalone
  Git realization, and clean-acquisition proofs; and
- Apache-2.0 licensing, lightweight DCO governance, security reporting,
  best-effort support, and local release-readiness evidence.

Clinical validation, production authorization, automated scheduling, remote
deployment, and OCI/container delivery are not included.
